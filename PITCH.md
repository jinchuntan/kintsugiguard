# KintsugiGuard AI — 3-Minute Demo Script

## 1. Problem (30s)

Enterprises are adopting AI agents to automate infrastructure, DevOps, and software operations. But these agents create three compounding problems:

- **Software waste** — bloated images, idle compute, duplicate API calls silently burn budget and carbon
- **Agentic risk** — autonomous agents make repair decisions without governance oversight
- **No audit trail** — when something goes wrong, there's no record of what the agent did or why

The result: engineering teams don't trust autonomous repair, so waste accumulates unchecked.

## 2. Inspiration (20s)

Kintsugi is the Japanese art of repairing broken pottery with gold. The repair is visible, intentional, and makes the object stronger.

KintsugiGuard AI applies this philosophy to enterprise software:
- Cracks = software waste and agentic risk
- Gold repairs = safe, policy-approved improvements
- The repair ledger = audit-ready governance trail

## 3. Solution (40s)

KintsugiGuard AI is an enterprise AI governance and repair platform with 10 coordinated agents:

- **Detection agents** find waste: bloated containers, idle compute, duplicate AI calls, excessive cloud spend
- **Governance agents** enforce policy: check whether repairs are allowed, flag security risks, record decisions
- **Repair agents** plan and prioritize: rank fixes by impact, confidence, effort, and risk
- **Audit agents** log everything: what was found, what was recommended, what was approved or blocked

Every action is governed. Every decision has provenance.

## 4. Demo Flow (60s)

1. Select an enterprise audit package (e.g., a SaaS backend with $1,670/mo waste)
2. Watch 10 agents run the workflow — detection, governance, repair planning
3. View findings dashboard — cost, carbon, severity, confidence for each crack
4. Open governance dashboard — see which repairs are auto-approved, which need human review, which are blocked
5. Show X402 governed payment — agent requests paid API, governance checks budget, payment logged in audit trail
6. Export impact report — executive summary with governance findings, savings, and KintsugiGuard Score

## 5. Enterprise Value (30s)

- **Cost savings**: $20K-$42K annual savings per audited system
- **Carbon reduction**: 38-156 kgCO2e/month avoided per system
- **Governance**: every agent action recorded with decision provenance
- **Safety**: policy enforcement prevents unsafe autonomous repairs
- **Compliance**: audit-ready logs for security and governance teams

## 6. Hackathon Fit (20s)

- **Agent Security & AI Governance** — governance policy enforcement, security inspection, audit trail
- **Google AI Studio / Gemini** — Gemini-ready architecture for reasoning, classification, summarization
- **Data & Intelligence** — multi-agent waste detection and impact estimation
- **Enterprise deployment** — mock-safe demo with clear path to production integration

## 7. Closing (10s)

> KintsugiGuard AI turns software waste and agentic risk into governed, measurable enterprise repair.
> Every crack gets a gold fix. Every fix gets a policy check. Every check gets an audit entry.
